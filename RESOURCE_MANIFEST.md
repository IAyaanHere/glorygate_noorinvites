# Resource Manifest

## HTML & Core
- `index.html`: Main HTML, localized scripts and styles.
- `src/styles.css`: Main styling.
- `fonts.css`: Local generated Google Fonts reference.
- `src/app.js`: Application logic.
- `src/config.js`: Configuration data.
- `src/components/render.js`: Component rendering.
- `src/lib/scratch.js`: Date reveal scratch logic.
- `src/lib/petals.js`: Petal animation logic.

## Media
- `bismillah.mp3`: Background audio track.
- `assets/video/eden-intro-placeholder.mp4`: Intro background video.
- `assets/video/eden-intro-poster.webp`: Video poster.
- `assets/gallery/gallery-01.jpg` to `gallery-05.jpg`: Sample gallery images.

## Fonts
- `assets/fonts/*.woff2`: Manrope, Parisienne, and Cormorant Garamond Google Fonts hosted locally.
